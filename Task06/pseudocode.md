# Task 06 – Fare Calculation Methods

## Aim
To implement metro fare calculation using a switch statement and a fare table.

## Pseudocode

1. Start the program.
2. Read the zone number, peak-hour status and concession status.
3. Select the base fare for the chosen zone.
4. If peak hour is enabled, add the peak surcharge.
5. If concession is enabled, apply the concession percentage.
6. Display the final fare in paise.
7. Stop.

## Fare Values
- Inner Zone: 1000 paise
- Middle Zone: 2000 paise
- Outer Zone: 3000 paise
- Peak surcharge: 20%
- Concession: 50% (project assumption)

## Result
The fare calculation logic is represented using two approaches: a switch statement and a fare table.
