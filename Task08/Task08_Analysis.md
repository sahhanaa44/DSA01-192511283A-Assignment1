# Task 08 – Input Handling in C++

## Aim
To understand input handling using `cin` and `getline()` in C++.

## `cin`
The `cin` statement reads input until whitespace is encountered. Therefore, it reads only the first word of a full name.

## `getline()`
The `getline()` function reads an entire line, including spaces. It is suitable for entering a passenger's full name.

## Validation
The programs accept zone values from 1 to 3. Any other zone value displays an invalid-zone message.

## Test Cases
1. Enter a single-word passenger name and a valid zone.
2. Enter a full name containing spaces.
3. Enter an invalid zone such as 5.

## Result
Both programs demonstrate input handling, and the difference between `cin` and `getline()` was observed.
